# Print GFG n times

**Difficulty:** Easy

## Description

<p><span style="font-size: 18px;">Given a positive number <strong>n</strong>, print the string "<strong>GFG</strong>" exactly n times separated by a single space.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 5
<strong>Output:</strong></span><span style="font-size: 18px;">
GFG GFG GFG GFG GFG</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> 3<strong>
Output:</strong></span><span style="font-size: 18px;">
GFG GFG GFG</span></pre>
<p><strong><span style="font-size: 18px;">Constraint:</span></strong><br /><span style="font-size: 18px;">1 </span><span style="color: #222222; font-family: inherit; font-size: 15.008px; letter-spacing: 0.01px; white-space: pre-wrap;">&le; </span><span style="font-size: 18px;">n&nbsp;</span><span style="color: #222222; font-family: inherit; font-size: 15.008px; letter-spacing: 0.01px; white-space: pre-wrap;">&le; </span><span style="font-size: 18px;">10<sup>3</sup></span></p>
