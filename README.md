## 📁 Architecture & Organization

The repository follows a standardized structure for every problem to ensure clean navigation. Inside each platform's root directory, problems are organized into their own dedicated folders. 

Every individual problem folder contains:

*   📄 **`README.md`**: Contains the complete problem statement, description, and any constraints.
*   💻 **Language Folders (e.g., `C++`)**: Contains the actual code implementations organized by the language used.
    *   🔢 **`solution-1.cpp`, `solution-2.cpp`, etc.**: The files are sequentially numbered to represent my total successfully solved attempts, iterative improvements, or alternative approaches (like moving from a brute-force approach to an optimal one).
